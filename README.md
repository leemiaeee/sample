# **1.top**
시스템의 실시간 성능 및 프로세스 상태를 동적으로 모니터링 하는 명령어
### 주요용도
-CPU 및 메모리 사용량 실시간 확인

-시스템 부하 파악

-자원 점유율이 높은 프로세스 식별 및 즉시 종료

-실행 중인 프로세스 정보 실시간 업데이트
### 주요 정보
|필드|설명|
|:---|:---|
|Load average|1분,5분,15분 동안의 평균 실행/대기 중인 프로세스 수|
|%CPU|사용자, 시스템, 유휴 시간 등 CPU 사용률 세부 정보|
|KiB Mem|전체, 사용 중, 여유, 버퍼/캐시 메모리 사용량|
### 프로세스별 상세 정보
|필드|설명|
|:---|:---|
|PID|프로세스 고유 ID|
|USER|프로세스를 실행한 사용자|
|VIRT|프로세스가 사용하는 전체 가상 메모리 크기|
|RES|실제 물리 메모리 사용량|
|%CPU|프로세스가 사용하는 CPU 비율|
|%MEM|프로세스가 사용하는 물리 메모리 비율|
|S|프로세스 상태(R: 실행 중, S: 대기, Z: 좀비)|
### 실행 중 유용한 단축키
|단축키|기능|
|:---|:---|
|Shift + P|CPU 사용률 기준 정렬|
|Shift + M|메모리 사용률 기준 정렬|
|k|선택된 프로세스에 kill 시그널 전송|
|i|CPU 코어별 사용량 토글|
|q|top 종료|
# **2.ps**
명령어가 실행된 **특정순간(스냅샷)** 의 프로세스 상태를 정적으로 표시
### 주요 용도
-특정 프로세스의 PID 및 PPID 확인

-현재 시스템에서 실행 중인 프로세스 목록 확인

-특정 데몬이나 서비스의 실행 상태 확인
### 자주 사용되는 옵션
|옵션|설명|
|:---|:---|
|ps -ef|모든 프로세스를 System V 스타일의 전체 포멧으로 표시|
|ps aux|모든 사용자의 모든 프로세스를 BSD 스타일로 표시|
### 활용 예시
특정 프로그램(mysql)의 프로세스 ID를 찾을 때 grep과 함께 사용

$ ps -ef | grep mysql
# **3.jobs**
현재 셀 세션에서 실행 중이거나 일시 정지된 **작업** 의 상태 목록을 표시
### 주요 용도
-백그라운드 또는 일시 정지된 작업 확인

-백그라운드 작업을 포그라운드로 전환하거나 재개할 때 작업 번호 확인
### 작업 제어 명령어
|명령어|기능|
|:---|:---|
|[COMMAND &]|명령어를 백그라운드로 실행|
|Ctrl + Z|포그라운드 작업을 일지 정지 상태로 전환|
|jobs|현재 작업 목록 확인|
|fg %N|N번 작업을 포그라운드로 가져옴|
|bg %N|N번 작업을 백그라운드로 재개|
### 옵션
jobs -l: 작업 번호화 함께 프로세스 그룹 ID(PID)도 표시하여 kill 명령어와 연계하기 편리
# **4.kill**
지정된 프로세스에 **시그널** 을 보내 제어하는 명령어
### 주요 용도
-응답 없는 프로세스를 강제로 종료

-프로그램을 안전하게 종료하거나 재시작하도록 요청
### 기본 사용법
$ kill [-시그널번호 또는 시그널명] PID
### 주요 시그널 목록
|번호|이름|설명|용도|
|:---|:---|:---|:---|
|15|SIGTERM|정상 종료 요청 시그널. 프로세스가 자원을 정리할 시간을 준다.|안전한 종료 시 권장|
|9|SIGKILL|강제 종료 시그널. 프로세스가 무시할 수 없으며 즉시 종료된다.|응답 없는 프로세스 종료|
|1|SIGHUP|연결 끊김. 보통 프로세스에게 재시작 및 설정 파일 재로드를 요청|서버 데몬 재시작|
|19|SIGSTOP|프로세스 일시 정지|임시 정지|
### 활용 예시
-정상적인 종료 요청:

$ kill 1234   # PID 1234에게 SIGTERM(15) 시그널 전송

-강제 종료:

$ kill -9 1234 # PID 1234를 SIGKILL(9)로 강제 종료

-작업 번호를 이용한 제어:

$ kill -STOP %1 # 1번 작업(Job)을 정지 시그널로 멈춤
